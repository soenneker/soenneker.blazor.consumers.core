# Soenneker.Blazor.Consumers.Core

A class that represents the core Blazor Consumer, providing no additional functionality than access to Soenneker.Blazor.ApiClient.

## Install

```bash
dotnet add package Soenneker.Blazor.Consumers.Core
```

## What you get

- `ICoreConsumer` — A class that represents the core Blazor Consumer, providing no additional functionality than access to Soenneker.Blazor.ApiClient.
